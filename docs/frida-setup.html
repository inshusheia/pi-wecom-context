Frida 安装与取钥步骤

WeCom Context 离线随附说明 · 版本 1.0.0 · Frida 17.18.0

普通用户无需手动安装

DMG 内的 WeCom Context.app 已经内置 Frida 及 arm64 原生模块。直接把 App 拖入“应用程序”并启动即可，不需要安装 Python、pip 或 Frida。

只有在源码调试或修复旧安装包时才需要安装

  1. 打开“终端”，进入项目的 source 目录：
cd ~/Desktop/pi-wecom-context/source
  1. 让项目脚本自动安装适用于 Apple Silicon 的 Frida：
sidecar/.venv/bin/python scripts/capture_enterprise_key.py

脚本会通过本机代理 http://127.0.0.1:7897 从 PyPI 下载 arm64 abi3 wheel，并安装到项目虚拟环境。没有代理时，请先配置可访问 PyPI 的网络。

  1. 检查安装结果：
sidecar/.venv/bin/python -c 'import frida; print(frida.__version__)'

预期输出：17.18.0 或项目要求的兼容版本。

提取企业微信数据库密钥

  1. 启动企业微信，并确认当前登录账户属于要读取的目标企业。
  2. 确认目标企业的数据目录已经重新生成。
  3. 运行脚本，按提示选择数据集：
sidecar/.venv/bin/python scripts/capture_enterprise_key.py

脚本只读附加企业微信进程并扫描密钥，不上传聊天内容。密钥验证成功后才会写入本机 vault。

仍然看到 CAPTURE_FAILED / No module named 'frida'？

如果使用的是安装版，请退出旧版 WeCom Context，重新从本 DMG 安装最新版；如果使用源码版，请重新执行上面的安装和版本检查命令。安装版不应要求用户自行执行 pip。

本页是随 DMG 一起分发的离线说明，不依赖网络。请勿把密钥文件、企业微信数据库或聊天内容发送给他人。
